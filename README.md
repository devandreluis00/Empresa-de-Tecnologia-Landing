# 💻 Empresa de Tecnologia | Soluções Digitais Modernas

Uma **empresa de tecnologia moderna** que oferece desenvolvimento web, mobile, sistemas personalizados, automação, consultoria tech e soluções digitais inovadoras. Este projeto é um exemplo de **front-end profissional**, combinando HTML, CSS moderno, JavaScript e boas práticas de UX/UI.

## 🔹 Funcionalidades

* **Tema claro e escuro** com armazenamento em `localStorage`.
* Seção **Hero** com chamada para ação.
* Seção **Sobre Nós** detalhando a empresa e expertise.
* Seção **Serviços** com cards interativos:
  * Desenvolvimento Web
  * Sistemas Personalizados
  * Consultoria Tech
  * Automação
  * Inteligência Artificial
  * Cloud Computing
  * Desenvolvimento Mobile
  * Cibersegurança
* **Formulário de Contato** funcional com mensagem de sucesso.
* **Informações de contato**: email, telefone e localização.
* **Mapa de localização** integrado via Google Maps.
* Layout **100% responsivo** para desktop, tablet e mobile.
* Uso de **HTML semântico**, **SEO básico** e **schema.org**.
* Animações suaves e efeitos modernos nos cards e botões.

## 🔹 Tecnologias Utilizadas

* **HTML5** – Estrutura semântica do site  
* **CSS3** – Estilização, temas e responsividade  
* **JavaScript (Vanilla JS)** – Interatividade (tema, scroll e formulário)  
* **Google Fonts (Inter)** – Tipografia elegante  
* **Schema.org JSON-LD** – Dados estruturados para SEO
